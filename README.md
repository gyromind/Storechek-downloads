# Storechek Pilot downloads

Windows frontend test build for coworkers using an existing Storechek test database.

- [Download the Windows installer (0.1.1)](https://github.com/gyromind/Storechek-downloads/releases/download/v0.1.1-test/Storechek.Pilot_0.1.1_x64-setup.exe)
- [Download the setup guide](https://github.com/gyromind/Storechek-downloads/releases/download/v0.1.1-test/READ-ME-FIRST.txt)
- [Open the test release](https://github.com/gyromind/Storechek-downloads/releases/tag/v0.1.1-test)

No GitHub account is required to download these files.

Before installing, configure and test your SQL Server DSN in **ODBC Data Sources (64-bit)**. The default DSN name and required database name are **BackOfficeSQL**. This build uses Windows authentication and existing Storechek permissions.

The installer is unsigned. The app is read-only and intended for testing; it does not replace Access. See the setup guide for requirements and troubleshooting.

This repository contains only download information. Application source code is maintained separately.
